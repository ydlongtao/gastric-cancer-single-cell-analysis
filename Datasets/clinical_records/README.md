# Clinical Records

本目录用于存放胃癌单细胞/空间转录组项目相关病历资料和样本临床注释。

建议文件类型：

- 样本信息表：患者编号、样本编号、组织来源、取样部位、批次。
- 临床信息表：年龄、性别、诊断、分期、治疗、疗效、随访等。
- 数据字典：每一列的含义、单位、取值范围、缺失值编码。
- 样本映射表：临床编号、测序编号、GEO/SRA/GSA 编号之间的对应关系。

注意事项：

- 不要在公开版本库中提交可识别个人身份的信息。
- 临床资料导入分析前，应先生成去标识化版本。
- 样本 ID 需要与 `Datasets/*/raw/*meta*` 或处理后的对象元数据保持一致。
