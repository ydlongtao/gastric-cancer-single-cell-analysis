核心结论

本次盲法注释在 broad lineage 层面表现较好：原始数据与既有注释的 broad lineage ARI 为 0.898 ，NMI 为 0.828 ；模拟数据与参考标签的 broad lineage ARI 为 0.999 ，NMI 为 0.996 。这说明 200 基因合并对象足以恢复 T/NK、B/Plasma、Myeloid/TAM、Stromal 等大类结构。

但 fine celltype 层面一致性明显较低：原始细胞精细 celltype ARI 只有 0.120 ，模拟参考标签 ARI 为 0.310 。因此，报告中的 cluster 注释应被理解为大类细胞身份，而不是 CD4/CD8/TAM 细分状态的最终判定。

Cluster Annotation Summary 总览

合并对象共形成 19 个 cluster。主要成分为 T cell、Myeloid/TAM、NK cell、Plasma cell、B cell，并包含少量 Endothelial 与 Fibroblast/Pericyte。大多数 cluster 的 marker 面板和 SingleR HPCA 映射方向一致，因此可信度为 high；两个 cluster 因参考冲突或参考映射不稳定被标为 medium。

需要重点谨慎解释的 cluster

Cluster 15：Myeloid/TAM 与 Endothelial 信号冲突

Cluster 15 的 marker 面板最高为 Myeloid/TAM，但分数优势较小；SingleR 则指向内皮相关标签。它可能代表髓系/内皮信号混合、低信息量 cluster、或者 200 基因限制导致的参考漂移。建议在后续高基因数模拟或全基因原始对象中复核。

Cluster 18：浆细胞 marker 清楚，但 HPCA 映射异常

Cluster 18 包含 JCHAIN、MZB1、DERL3 等浆细胞证据，因此注释为 Plasma cell；但 SingleR 给出 GMP，说明 HPCA 在当前 200 基因子集上无法稳定识别这个小 cluster。该群可以作为浆细胞倾向使用，不建议进一步拆分。

Cluster 17：原始细胞高度富集的炎症性髓系群

Cluster 17 由 S100A8、FCN1、S100A9、LYZ 等支持，SingleR 指向 CD14+ Monocyte；同时原始细胞比例达到 96.3%。这提示它可能是原始数据中真实存在但模拟扩增不足的状态，应在比较原始与模拟表现时单独关注。
